📘 تعليم HTML – إصدار محسّن

ما هي HTML؟

HTML هي اختصار لـ HyperText Markup Language وتعني لغة ترميز النص التشعبي. وهي الأساس الذي تُبنى عليه جميع صفحات الويب، حيث تحدد بنية الصفحة ومحتواها.

أبسط مثال على صفحة HTML

هذا مثال قياسي لأي صفحة HTML:

<!DOCTYPE html>
<html>
  <head>
    <title>صفحة بسيطة</title>
  </head>
  <body>
    <h1>أهلاً بالعالم!</h1>
  </body>
</html>

هيكل صفحة HTML (رسم توضيحي)

📄 HTML Document ├── <head> │ ├── <title> │ └── meta tags └── <body> ├── <h1> ├── <p> └── <img>

أهم الوسوم الأساسية

الوسم وظيفته يحتاج إغلاق؟ مثال
<h1> عنوان رئيسي نعم <h1>عنوان</h1>
<p> فقرة نصية نعم <p>نص</p>
<a> رابط قابل للضغط نعم <a href="#">اضغط هنا</a>
<img> صورة لا <img src="image.jpg" alt="صورة">
<div> قسم أو حاوية نعم <div>محتوى</div>

أمثلة سريعة

📌 عنوان

<h1>هذا عنوان رئيسي</h1>

📝 فقرة

<p>هذه فقرة توضيحية.</p>

🔗 رابط

<a href="https://example.com">زيارة الموقع</a>

🖼️ صورة

<img src="image.jpg" alt="صورة">

خطوات عملية للبدء

  • افتح محرر VS Code.
  • أنشئ ملف جديد باسم index.html.
  • الصق مثال HTML الأساسي.
  • افتح الملف في المتصفح.
  • غيّر النصوص وشاهد التغييرات مباشرة.

ملاحظات مهمة

  • HTML ليست لغة برمجة.
  • المتصفح يفسر الوسوم ولا ينفذها.
  • احرص على كتابة الوسوم بشكل صحيح.
  • استخدم المسافات (Indentation) لترتيب الكود.
